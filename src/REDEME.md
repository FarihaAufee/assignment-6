Project Name:
FitLog – Workout Tracker

Short Description:
FitLog is a responsive workout tracking web application where users can explore workouts, view workout details, save workouts for later, and add exercises to their daily training plan.

Technologies Used:

Next.js
React
TypeScript
Tailwind CSS
DaisyUI
Lucide React
React Toastify
REST API
LocalStorage

5 Key Features:

Browse and explore workouts from the workout library.
View detailed information including equipment, difficulty, sets, reps, duration, calories, and rating.
Add workouts to Today's Plan and manage planned exercises.
Save workouts for later and manage saved workouts.
Responsive design for mobile, tablet, and desktop devices.
